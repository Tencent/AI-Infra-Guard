# PAMELA reference distributions

`distributions.json` is the generated model-distribution dataset consumed by
the integrated PAMELA matcher. It was copied from
`pamela-publish-data/results/distributions.json` and whitespace-compacted to
one record per line; the decoded JSON data is unchanged.

- Project: PAMELA — Probing And Measuring Emergent LLM Alignments
- Dataset reference used by the upstream integration: Zenodo 21278557
- Upstream SHA-256 before whitespace compaction: `6fbb713e2269fbd68f39a0e8cb39c0ceb9eb5c9218095b631ebbb53455bc17cb`
- Bundled compacted SHA-256: `bc22d9de5dee39f623e13cee15e0c206f967978757a2323586672091ebca8a54`
- The local upstream project declares the PAMELA package as MIT and describes
  the dataset artifact as intended for CC-BY publication.

Set `AIG_PAMELA_REFERENCE` to use a newer or externally mounted reference
file without changing the bundled default.
